# Olist E-commerce Analysis

## Project Overview

This project focuses on analyzing Brazilian e-commerce data using SQL to understand order performance, customer behavior, seller performance, payment methods, product categories, and delivery performance.

The analysis was performed using multiple related tables from the Olist e-commerce dataset.

## Tools & Technologies

- SQL
- SQL Server

## Dataset

- Domain: E-commerce
- Dataset: Olist Brazilian E-commerce Dataset
- Source: Kaggle

The dataset contains multiple related tables covering orders, customers, sellers, payments, products, reviews, and order items.

## Data Validation

Basic data validation checks were performed before analysis to understand the structure and quality of the data.

The validation included:

- Checking table structures
- Reviewing record counts
- Checking relevant columns and data types
- Validating relationships between tables
- Checking order and payment information

## SQL Analysis

SQL was used to answer business-related questions and analyze different aspects of the e-commerce data.

The analysis included:

- Order status analysis
- Customer analysis
- Seller sales performance
- Product category performance
- Payment method analysis
- Order delivery time analysis
- Customer state analysis
- Monthly order trends
- Sales value analysis
- Percentage-based analysis
- Ranking sellers and products
- Using JOINs, aggregations, CTEs, subqueries, and window functions

## Key Insights

- Delivered orders represented the largest share of orders.
- Credit card was the highest-value payment method.
- Beleza & Saúde was among the highest-performing product categories by sales value.
- Seller `4869f7...` recorded the highest sales value in the analysis.
- August recorded the highest number of orders among the analyzed months.

This project helped analyze a real-world e-commerce dataset using SQL and extract meaningful business insights from multiple related tables.
